# カジノポーカー（DQ風）

ドラゴンクエストシリーズのカジノに登場する「ポーカー」を再現した、ブラウザで遊べるファンメイドゲームです。
ビルド不要の単一HTMLファイルで、ダウンロードしてブラウザで開くだけ、あるいは GitHub Pages にそのまま公開するだけで遊べます。

▶ **[このゲームで遊ぶ](./dq-poker.html)**（GitHub Pages公開後はこちらのリンクが有効になります）

## 特徴

- 5枚のカードから1回だけ交換して役を作る、ビデオポーカー形式
- シリーズおなじみの絵柄「スライム／王冠／剣／盾」＋ジョーカー（ベビーサタン）
- オリジナル役「ロイヤルストレートスライム（500倍）」を含む、原作準拠の役と倍率
- A-2-3-4-5（ホイール）もストレート／ストレートフラッシュとして成立
- ダブルアップはハイ&ローカード形式を採用。的中で倍々、外れると没収。無制限に続行可能
- コインが尽きても自動で1000枚補充されるので、気軽に何度でも遊べる
- 所持コインはブラウザの `localStorage` に自動保存。リロードしても引き継がれる（ブラウザ・端末ごと）
- DQシリーズおなじみの、黒地に白文字のメッセージウィンドウ＋コマンド選択カーソル（▶）を再現したUI
- タイトルロゴ「CASINO POKER」は、ブロック（正方形タイル）を実際に組み立てて文字を描画するドットマトリクス方式
- ビルドツール不要。1つのHTMLファイルで完結（React / ReactDOM はCDN読み込み、JSXは事前コンパイル済み、Tailwindも不使用）

## 遊び方

1. 「スタート」を押す前に、賭け枚数を10枚/100枚単位で調整する（最大1000枚）
2. 「スタート」を押すと5枚のカードが配られる。残したいカードをクリックして「HOLD」表示にする
3. 「チェンジ」を押すと、HOLDしなかったカードだけ新しいカードに交換される
4. 役ができていれば配当を獲得。「ダブルアップ」に挑戦するか、「やめておく」で受け取るか選べる
5. ダブルアップでは、表示されたカードより次のカードが「高い」か「低い」かを予想。的中すれば倍額、外れると没収（引き分けはやり直し）。「やめる」でいつでも回収できる

## 役一覧（倍率）

| 役 | 倍率 |
|---|---|
| ロイヤルストレートスライム | 500倍 |
| ロイヤルストレートフラッシュ | 100倍 |
| ファイブカード（4カード＋ジョーカー） | 50倍 |
| ストレートフラッシュ | 20倍 |
| フォーカード | 10倍 |
| フルハウス | 5倍 |
| フラッシュ | 4倍 |
| ストレート | 3倍 |
| スリーカード | 1倍 |
| ツーペア | 1倍 |

※ワンペアは役として扱われません（原作準拠）。
※A-2-3-4-5（ホイール）もストレート扱いになります。ただしスライム絵柄で揃えてもロイヤルストレートスライムにはならず、ストレートフラッシュ止まりです（原作のRSSは10・J・Q・K・A限定のため）。

## セーブデータについて

所持コインは、ゲームを操作するたびにブラウザの `localStorage`（キー: `dq-poker-save`）に自動保存されます。

- 同じブラウザ・同じ端末であれば、タブを閉じたりリロードしても続きから再開できます
- PCとスマホ、Chrome とSafariなど、ブラウザや端末が変わると保存内容は引き継がれません
- シークレット/プライベートブラウジングでは保存されません
- キャッシュやサイトデータを削除すると、保存内容も消えます

## GitHub Pagesでの公開方法

1. このリポジトリに `dq-poker.html` をアップロード（`index.html` にリネームするとURLが短くなります）
2. リポジトリの **Settings → Pages** を開く
3. **Branch** を公開したいブランチ（例: `main`）、フォルダを `/ (root)` に設定して保存
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになります

## 技術構成

- React 18 / ReactDOM（CDN読み込み）
- JSXは事前にプレーンなJavaScriptへコンパイル済み（ブラウザ内でのBabel変換は不使用。「Cannot use import statement」等のランタイムエラーを避けるための対応）
- スタイルは自前の軽量CSS（Tailwind CDN不使用。本番環境向けの警告が出ないようにするため）
- タイトルロゴはSVGで、文字ごとに5×7ドットのブロックパターンを定義し、実際に四角形を並べて描画
- 所持コインの永続化は `localStorage` のみ（サーバー・DBなし）
- 外部ビルドツール・npm不要。ファイルを開くだけで動作
