# カジノポーカー（DQ風）

ドラゴンクエストシリーズのカジノに登場する「ポーカー」を再現した、ブラウザで遊べるファンメイドゲームです。
ビルド不要の単一HTMLファイルで、ダウンロードしてブラウザで開くだけ、あるいは GitHub Pages にそのまま公開するだけで遊べます。

▶ **[このゲームで遊ぶ](./dq-poker.html)**（GitHub Pages公開後はこちらのリンクが有効になります）

## 特徴

- 5枚のカードから1回だけ交換して役を作る、ビデオポーカー形式
- シリーズおなじみの絵柄「スライム／王冠／剣／盾」＋ジョーカー（ベビーサタン）
- オリジナル役「ロイヤルストレートスライム（500倍）」を含む、原作準拠の役と倍率
- ダブルアップはハイ&ローカード形式を採用。的中で倍々、外れると没収
- コインが尽きても自動で補充されるので、気軽に何度でも遊べる
- DQシリーズおなじみの、青いメッセージウィンドウ＋コマンド選択カーソル（▶）を再現したUI
- ビルドツール不要。`index.html` 1つで完結（React / ReactDOM は CDN 読み込み、JSXは事前コンパイル済み）

## 遊び方

1. コインを賭ける（10枚 or 100枚単位、最大1000枚）
2. 5枚のカードが配られる。残したいカードをクリックして「HOLD」表示にする
3. 「チェンジする」を押すと、HOLDしなかったカードだけ新しいカードに交換される
4. 役ができていれば配当を獲得。「ダブルアップ」に挑戦するか、「やめておく」で受け取るか選べる
5. ダブルアップでは、表示されたカードより次のカードが「高い」か「低い」かを予想。的中すれば倍額、外れると没収（引き分けはやり直し）

## 役一覧（倍率）

| 役 | 倍率 |
|---|---|
| ロイヤルストレートスライム | 500倍 |
| ロイヤルストレートフラッシュ | 100倍 |
| ファイブカード（4カード＋ジョーカー） | 50倍 |
| ストレートフラッシュ | 20倍 |
| フォーカード | 10倍 |
| フルハウス | 5倍 |
| フラッシュ | 4倍 |
| ストレート | 3倍 |
| スリーカード | 1倍 |
| ツーペア | 1倍 |

※ワンペアは役として扱われません（原作準拠）。

## GitHub Pagesでの公開方法

1. このリポジトリに `dq-poker.html` をアップロード（`index.html` にリネームするとURLが短くなります）
2. リポジトリの **Settings → Pages** を開く
3. **Branch** を公開したいブランチ（例: `main`）、フォルダを `/ (root)` に設定して保存
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになります

## 技術構成

- React 18 / ReactDOM（CDN読み込み）
- JSXは事前にプレーンなJavaScriptへコンパイル済み（ブラウザ内でのBabel変換は不使用）
- スタイルは自前の軽量CSS（Tailwind CDN不使用）
- 外部ビルドツール・npm不要。ファイルを開くだけで動作
